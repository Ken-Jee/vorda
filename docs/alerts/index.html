    Check your own machines

    vorda checks what is actually installed on your machine: OS packages, lockfiles, tools, browsers, and MCP servers. It runs locally with no account and no telemetry. This command checks against the local offline database by default (npm, PyPI, crates.io, and Go); OS packages, tools, and browsers need --online (otherwise they report unknown).

    vorda scan --root ~/projects --os-packages --tools --browsers
