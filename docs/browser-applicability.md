# Chrome applicability and saved findings

Chrome catalog checks cover only the latest 119 publication days. An empty result never clears the browser's full history. Older missing advisories and unsupported applicability rules stay unknown.

A fresh online catalog record with supported applicability can close that advisory alone once the observed version reaches or passes every affected interval's exclusive fixed end. Closure requires the same scan scope, package name, ecosystem, path, and package scope, but the old version does not have to equal the new one. Unrelated older findings stay open; offline catalogs, future timestamps, and incomplete or stale imported inventory never grant this authority.

The mailbox records closure without deleting findings, messages, delivery receipts, or history. The scan still reports limited-history/unknown even when a saved advisory closes. This is not a general CPE evaluator or historical crawl.
